# Electronic Instrumentation and Measurements

**Book:** Electronic Instrumentation and Measurements  
**Author:** David A. Bell  
**Edition:** 2nd Edition

## About
This repository contains a reference for the Electronic Instrumentation and Measurements course, collected and organized by **Khaled Taha** to help students with their studies.

## Purpose
To make useful academic references easier to access and share with fellow students.
